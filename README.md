# genpark-agentic-markdown

A markdown processor optimized for human-AI co-creation.

Stop paying for closed SaaS apps. This is a terminal-native, open-source alternative to **Cogito**.

Instead of a standalone app, this skill turns your IDE/terminal into a collaborative workspace. Write a bullet point, let the agent expand it, format it, and automatically execute any embedded code blocks.

## Usage
```bash
openclaw use genpark-agentic-markdown
```
